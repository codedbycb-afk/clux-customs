# C-Lux Customs: preview

Preview of the C-Lux Customs booking site and shop app, built by Twenty47 Marketing.

- **Site:** https://codedbycb-afk.github.io/clux-customs/
- **Shop app:** https://codedbycb-afk.github.io/clux-customs/app/ (passcode `2477`)

This copy runs on sample data in your browser. Bookings made here don't go anywhere and nothing touches a real calendar. The live version, with Apple Calendar sync, goes up on the shop's own domain.

This repo is generated. Edit the source project and run `npm run preview:build`.
